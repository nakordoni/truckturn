# TruckTurn: HGV Navigator

### Навігація, створена для професійних водіїв вантажівок.

![TruckTurn](https://nakordoni.eu/truckturn/store/icon_512.png)

TruckTurn прокладає маршрут для вашого реального транспортного засобу, показує, що попереду, і з'єднує вас з іншими водіями. Спочатку для Android; версія для iOS у розробці.

## Можливості

- **Маршрути для вашої вантажівки**: висота, вага, ширина, довжина, навантаження на вісь і ADR
- **Попередній перегляд маршруту** з альтернативами, оцінкою вартості проїзду та опцією уникати платних доріг
- **Заборони руху на маршруті** та обмеження за висотою, вагою й шириною
- **Дорожні події та погода** по шляху
- **Голосові підказки** зі смугами руху та обмеженням швидкості
- **Актуальні черги на кордоні** з окремо показаною смугою для вантажівок
- **Паркінги для вантажівок, пальне з AdBlue, ваги та мийки** попереду
- **Відлік часу керування** до наступної перерви (лише оцінка)
- **Режим безпечного водіння** з великими простими елементами керування в русі
- **Driver Connect**: чат зі наскрізним шифруванням і голосові повідомлення
- **Відеореєстратор** із циклічним записом; відео залишаються на вашому телефоні
- Денна й нічна мапа, портретна та ландшафтна орієнтація
